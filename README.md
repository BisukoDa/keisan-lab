# 暮らしの計算ラボ（自動運営サイト）

積立・ローン・日付・年齢・電気代・パーセントなどの計算ツールと解説記事を、Claude Code が毎日1本ずつ追加していく Web サイトです。Fable の審査に合格したページだけが自動で公開されます。収益源は広告（Google AdSense）とアフィリエイト（A8.net など）、目標は月3万円です。

- サイト：https://bisukoda.github.io/keisan-lab/
- 運営マニュアル（Claude が毎回読む手順書）：[CLAUDE.md](CLAUDE.md)
- 実行ログ：[ops/log.md](ops/log.md)、候補リスト：[ops/backlog.json](ops/backlog.json)

## 自動で回る部分（人の承認なし）

```
毎日 6:07（JST） Claude Code ルーティン（クラウド）が起動
  ├─ backlog から次のツールを選ぶ
  ├─ 公的資料で計算式・制度を調べる
  ├─ 計算ロジック + テスト + 解説記事を書く
  ├─ npm run verify（テスト・ビルド・機械チェック。ここで落ちたら直す）
  ├─ Fable が納品前審査 → 不合格なら修正して再審査（最大3回、2回目以降は Opus が修正）
  └─ 合格したら main に push
GitHub Actions が再検証 → GitHub Pages に公開（納品）
```

### モデルの使い分け

| 作業 | モデル |
| --- | --- |
| 機械で判定できるチェック（計算テスト・リンク切れ・禁止表現など） | なし（スクリプト、コスト 0） |
| 調査・執筆・初回の修正・進行管理 | Sonnet（ルーティン本体） |
| 納品前の最終審査 | Fable（1ページ最大3回） |
| 2回不合格になったページの修正 | Opus |
| トピック補充（週1）・月次レポート（月1） | Haiku |

## オーナーにしかできない初期設定（1回だけ）

本人確認・銀行口座・規約への同意が必要なものは、法律上も規約上も Claude が代行できません。上から順に、できるものから進めてください。

0. **（最優先・1分）ルーティンのネットワークを広げる**：クラウド環境の初期設定（Trusted）では官公庁サイト（go.jp など）に接続できず、Fable が出典を直接開いて確認できません。claude.ai/code/routines → このルーティン → Edit → 環境（Default）の設定アイコン → Network access を **Full**（または Custom にして `*.go.jp` `*.or.jp` `*.e-gov.go.jp` `www.flat35.com` などを追加）に変更して保存してください。未設定でも Fable は Web 検索で裏付けを取りますが、確認できない記述は不合格にするため、公開が止まりやすくなります。
1. **アフィリエイト（A8.net）に登録する**：メディア登録の URL は上記サイト。承認後、`config/affiliates.json` の枠（証券・住宅ローン・電力比較・会計ソフト）に合う広告に提携申請し、発行された広告タグを該当キーの `html` に貼って `enabled` を `true` にします。以降、関連するページに自動で表示され、「本ページはプロモーションを含みます」の表記も自動で付きます。
2. **独自ドメインを取る（年1,500円前後）**：AdSense は `github.io` のサブディレクトリでは審査を受けられないため必要です。取得後、`config/site.json` の `customDomain` に設定し、DNS に GitHub Pages 用のレコードを追加します（設定方法は GitHub Docs「Managing a custom domain for your GitHub Pages site」）。
3. **Google Search Console に登録する**：HTML タグ方式の確認コードを `config/site.json` の `searchConsoleVerification` に入れ、サイトマップ（`/sitemap.xml`）を送信します。検索に載るのが早くなります。
4. **AdSense に申請する（ツールが20〜30本になってから）**：承認されたら `config/site.json` の `adsense.client`（`ca-pub-…`）を設定します。自動広告と `ads.txt` が自動で出力されます。
5. **問い合わせ窓口**：現在は GitHub の Issue に設定しています。AdSense 審査を通りやすくするには、Google フォームを作って `config/site.json` の `contactUrl` を差し替えるのがおすすめです。

設定ファイルを変えたら、GitHub の Web 画面から直接編集して保存（コミット）すれば、数分で自動的に反映されます。

## 収益の見通し（正直なところ）

- 新しいサイトが検索経由で読まれ始めるまでには、通常3〜6か月かかります。最初の数か月は収益がほぼ0円です。
- 毎日1本ずつ増え、半年で約180本になります。月3万円は、検索流入が育てば開始から6〜12か月での到達を目指せる水準ですが、**達成は保証できません**。月次レポート（`ops/reports/`）で進み具合を確認し、伸びが悪ければトピックの選び方を変えます。
- 給与所得のある方は、副業の所得（収入から経費を引いた額）が年20万円を超えると確定申告が必要です。20万円以下でも住民税の申告は必要です。勤務先の副業規定も確認してください。

## 止めたいとき

claude.ai/code/routines でルーティンをオフにすると止まります。サイトはそのまま公開され続けます。

```
npm run verify      # テスト → ビルド → チェック
npm run serve       # http://localhost:4173/keisan-lab/ でプレビュー
```
